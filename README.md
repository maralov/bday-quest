# Сигнал з того боку

Квест на телефоні на 5–10 хвилин: чотири головоломки ведуть до чотирьох QR у квартирі, зібрані літери відкривають сейф, фінал називає схованку подарунка.

Сайт: https://maralov.github.io/bday-quest/ (деплоїться сам після пушу в `main`).

## Як грати

1. Дати дитині картку «СТАРТ»: QR відкриває сайт.
2. На кожному етапі головоломка підказує, де шукати наступну картку «Сигнал».
3. Картку сканувати **кнопкою «Зловити сигнал» на самому сайті**. Не системною камерою: вона відкриє посилання в іншому браузері (Safari), а прогрес зберігається в тому браузері, де почали.
4. Якщо камера на сторінці не працює, ввести код, надрукований під QR (наприклад `UP0U J3AH`).

Обмеження: один телефон, один браузер (або додаток), не приватна вкладка.

## Батьківська панель

Відкрий `https://maralov.github.io/bday-quest/?admin`, введи пароль. Там: поточний етап і кнопки 0–6, «Скинути прогрес», відповіді й схованки, QR для друку (кнопка «Друкувати», 5 карток на A4). Друкуй із задеплоєного сайту, не з localhost.

## Як змінити вміст

Усе лежить у `src/quest.json`. Після змін: `npm test`, пуш у `main`.

- Схованки (`hideAt`), тексти головоломок і підказки змінюються прямо в JSON. Якщо змінюєш місце, онови і текст головоломки, і другу підказку.
- Пароль панелі: `npm run hash -- "новий-пароль"`, результат у `adminPasswordHash`.
- Пароль сейфа: `npm run hash -- "ДИВО"` (великими літерами, кирилицею), результат у `safe.passwordHash`. Літери рівнів (`letter`) мають складати це слово.
- Схованка подарунка: `npm run b64 -- "Де лежить подарунок"`, результат у `finale.giftPlaceB64`.
- Нові токени QR: `npm run tokens`, вписати в `levels[].token`.

**Після зміни токенів чи адреси сайту QR треба надрукувати заново.**

Якщо в `quest.json` помилка (задовге слово для морзянки, повторний токен тощо), сайт покаже її текст замість квесту.
